## Project Requirements

- PHP 8.3 with the LAMP stack
- MySQL accessed through PDO with prepared statements
- `public/` is the Apache document root
- JSON for client-server communication
- AJAX for asynchronous API requests
- Server-side partial contact search
- All contact operations must be scoped to the authenticated user
- Never commit secrets or `.env` files
